## 接下来

### 2. 跨进程、跨机器的传递

`Transport` 现在只管内容本身，流和调用不经过它，也只有进程内的实现。要做的是“远端节点”：节点跑在另一个进程或另一台机器上，用一条连接收发信封（先 stdio 和 TCP，格式是一行一个 JSON）。设备接在别的机器上时需要它。`FolderNode` 每次激活启动一次进程，远端节点是常驻的。

### 3. 引擎改成协程

`arun` 现在是在线程里跑引擎。模型调用大多在等网络，并行的 agent 一多，线程开销就上来；`workers=4` 时每个信封约 85 微秒，是单线程的十倍，开销主要在线程交接。要做的是把调度核心写成协程，同步接口包在外面，节点的 `run` 可以是同步的（放进线程）也可以是协程。

### 4. 看得见的运行

`interlacing show`：把图画出来（导出 Mermaid 或 DOT），再按日志列出一次运行的时间线：哪个节点在第几轮、用了多久、花了多少、哪里出过问题。
